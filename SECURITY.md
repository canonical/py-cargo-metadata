# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

We track all issues, including security issues, through GitHub.
If private disclosure is not required, [open a new issue](https://github.com/canonical/py-cargo-metadata/issues/new).
If private disclosure is desired, [open a draft advisory](https://github.com/canonical/py-cargo-metadata/security/advisories/new).
